# Desafio de Projeto: Sistema de Cadastro de Biblioteca

Este projeto foi desenvolvido como parte do bootcamp de Ruby. O objetivo é simular o cadastro de utilizadores para a Biblioteca Municipal de São Paulo, capturando dados relevantes para o departamento de marketing.

## 🚀 Tecnologias e Conceitos Utilizados
* **Ruby**: Linguagem principal utilizada.
* **Entrada e Saída de Dados**: Uso de `puts` e `print` para interagir com o utilizador.
* **Manipulação de Strings**: Captura de dados com `gets.chomp` e uso de **interpolação** (`#{}`) para exibir mensagens personalizadas.
* **Conversão de Tipos**: Transformação de entrada de texto em número inteiro (`.to_i`) para processar a idade.
